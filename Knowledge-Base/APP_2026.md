// lib/services/transaction_parser_service.dart (NEW)
class TransactionParserService {
  final GenerativeModel _model;
  
  TransactionParserService() {
    _model = FirebaseAI.googleAI().generativeModel(
      model: 'gemini-2.5-flash',
    );
  }
  
  Future<TransactionData> parseNaturalLanguage(String input) async {
    final prompt = '''
Parse this transaction and extract structured data:
"$input"

Extract:
- amount (required, number)
- category (required, one of: Food, Transport, Shopping, Bills, etc.)
- merchant (optional, string)
- description (optional, string)
- date (optional, default to today)

Return JSON format:
{
  "amount": 0.0,
  "category": "Food",
  "merchant": "Starbucks",
  "description": "Coffee",
  "date": "2025-12-28"
}
''';

    final response = await _model.generateContent([
      Content.text(prompt)
    ]);
    
    return TransactionData.fromJson(
      jsonDecode(response.text!)
    );
  }
}
```

**Benefits:**
- ✅ Simple, reliable
- ✅ Single API call
- ✅ Easy to test
- ✅ User can confirm/edit before saving

class ReceiptAgent {
  final GenerativeModel _model;
  
  Future<ReceiptData> parseReceipt(String base64Image) async {
    final prompt = '''
Parse this receipt image and extract all transactions.

For each item, provide:
- item name
- quantity
- unit price
- total price

Also extract:
- merchant name
- total amount
- date
- payment method

Return as JSON array.
''';

    // Firebase AI supports multimodal inputs
    final response = await _model.generateContent([
      Content.multi([
        TextPart(prompt),
        InlineDataPart('image/jpeg', base64Decode(base64Image)),
      ])
    ]);
    
    return ReceiptData.fromJson(jsonDecode(response.text!));
  }
}
```

User's financial context:
$context

User question: "$question"

Answer their question helpfully and accurately.
''';

    ]);

class ReceiptParserServiceV2 {
  final GeminiClient _gemini;
  
  Future<ReceiptData> parseReceipt(File imageFile) async {
    final base64Image = base64Encode(imageFile.readAsBytesSync());
    
    final response = await _gemini.generateWithSchema(
      prompt: 'Parse this receipt and extract all transactions',
      images: [base64Image],
      schema: ReceiptSchema.jsonSchema,
      config: GenerationConfig(

      ),
    );
    
    return ReceiptData.fromJson(response.json);

**1. SDK Choice: Firebase AI ✅ VALIDATED**
- **Decision:** Keep using Firebase AI SDK (upgrade to 3.6.1)
- **Evidence:** Official Flutter SDK published 13 days ago, actively maintained by Google
- **Alternative Considered:** Migrate to REST API or google_generative_ai
- **Why This Choice:** Firebase AI IS the official SDK, REST would add complexity, google_generative_ai is deprecated
- **Regret Risk:** **0%** - This is the ONLY correct choice for Flutter/Dart

**2. No ADK Migration ✅ VALIDATED**
- **Decision:** Don't implement Google Agent Development Kit (ADK)
- **Evidence:** ADK supports Python, TypeScript, Go, Java ONLY (verified from official docs)
- **Alternative Considered:** Build custom agent framework
- **Why This Choice:** We ALREADY have agent architecture (orchestrator_agent, receipt_agent, etc.)
- **Regret Risk:** **0%** - Can't use ADK on Flutter, already have working agents

**3. Remove google_generative_ai ✅ VALIDATED**
- **Decision:** Delete deprecated package from pubspec.yaml
- **Evidence:** Package deprecated 8 months ago, Firebase AI replaces all functionality
- **Alternative Considered:** Keep both packages
- **Why This Choice:** Deprecated code is technical debt, Firebase AI does everything it did
- **Regret Risk:** **0%** - Keeping dead code is worse than removing it

**4. Keep Agent Architecture ✅ VALIDATED**
- **Decision:** Consolidate existing agents, don't rebuild from scratch
- **Evidence:** Working agents found: orchestrator_agent, receipt_agent, context_agent, item_tracker_agent
